**TubeAssistant / FERN** is an open-source AI video pipeline. The default renderer builds a chalk scene timeline from the narration, can interleave licensed real footage only when it passes topic and rights checks, creates a thumbnail, and can upload after the normal upload controls are satisfied.

No editing software. No recording. No scheduling. The agent runs 24/7 and you control it via Telegram.

---

## The Problem

Growing a YouTube channel is a second job. Every single day you need to:

- Research what topics are working
- Write a full script
- Record or synthesize a voice-over
- Find and edit video footage
- Design a thumbnail
- Write SEO-optimized titles, descriptions, and tags
- Upload and schedule at the right time
- Analyze performance and adapt

**Most creators quit within 3 months** — not because they lack ideas, but because the process is relentless and eats hours every day.

TubeAssistant eliminates every step. It runs 24/7, reads your channel analytics, generates content, and publishes — completely autonomously.

## Features

- **Full pipeline automation** — from topic idea to published video, zero human input
- **AI script generation** — LLM writes the script based on your niche and what's performing
- **George-only narration** — keeps the configured Kokoro George voice consistent across renders
- **Chalk chunk engine** — the default presentation, with drawings paced to narration and real footage used only when topic and reuse-rights checks pass
- **Rights-aware real footage** — a bounded Internet Archive search accepts only directly downloadable, topic-matched CC0/Public Domain Mark/CC BY footage; unsuitable results stay chalk-only
- **Legacy stock montage** — the previous Pexels/Openverse montage remains available by setting `FERN_RENDERER=clips`
- **AI video generation (optional)** — generate the clips with Replicate, fal.ai, Luma or
  OpenRouter instead of downloading them, with a per-video spend cap. OpenRouter has no
  text-to-video model: it generates the scene as an image and the clip is built locally with a
  camera move — a fraction of the cost, and it reuses the key you already use for scripts.
  Set it from the TUI: `tube-assistant clips`
- **Smart video editing** — FFmpeg montage with synced audio and background music
- **AI thumbnail** — generated by Pollinations.ai or HuggingFace FLUX with automatic text overlay
- **Analytics-driven** — reads your channel data, adapts topic and tone accordingly
- **Telegram control** — send a message, the agent obeys. Stop, force, queue topics, check stats
- **Crash recovery** — pipeline checkpoints resume from the last completed step
- **100% free tier** — OpenRouter, Pexels, Edge TTS, Pollinations.ai — all free

## How It Works

```
Analytics → Strategy → Script → George Narration → Chalk Chunk Timeline (+ verified licensed clips when found) → Thumbnail → Optional Upload
```

Every day, at the time you choose, TubeAssistant:

1. **Reads your channel analytics** to understand what's performing
2. **Picks a topic** aligned with your niche and goals
3. **Writes a full script** using an LLM (OpenRouter, Ollama Cloud, or local)
4. **Synthesizes narration** with Edge TTS — natural voice, zero cost
5. **Builds the scene timeline** — the chalk chunk engine is the default; it searches a bounded set of Internet Archive records for exact-topic CC0/Public Domain Mark/CC BY video and uses only sources that pass relevance, local-file, and license checks
6. **Falls back to chalk** whenever no suitable real clip passes the gates; the older Pexels/Openverse stock montage remains available as an explicit legacy mode
7. **Generates a thumbnail** with AI (Pollinations.ai or HuggingFace FLUX) + automatic text overlay
8. **Uploads to YouTube** and schedules at the optimal time

Everything controllable in real time via **Telegram** — just message your bot.

## Renderer modes

The production pipeline and one-shot runner use the **chalk chunk engine by default**. Each scene remains a chalk drawing unless footage has a matching title/topic, a real local MP4, a recognized reusable license, and accepted catalog/source evidence. Automatic discovery is deliberately limited to openly licensed Internet Archive clips; it does not scrape random YouTube channels. It can return no footage for a topic, in which case the chalk scenes are retained.

Set `FERN_AUTO_ARCHIVE_FOOTAGE=0` to disable the automatic archive search. To use an explicitly curated manifest instead, set `FERN_FOOTAGE_MANIFEST` to its path. The manifest is bound to the exact narration script hash; a stale manifest is ignored. The renderer writes a scene plan, a QA report, and a `.footage_attribution.txt` sidecar. When licensed footage is present, source attribution and license links are appended to upload metadata; publishing is blocked rather than silently dropping required credits.

To explicitly restore the old stock montage, add `FERN_RENDERER=clips` to `.env`. The renderer can be selected for a single Windows CMD session without permanently editing the environment:

```cmd
set FERN_RENDERER=clips
python main.py --dry-run
```

Remove that variable or set `FERN_RENDERER=chalk` to use the chunk engine again. The visual renderer switch does not change the configured narration voice or chalk sound-effect levels.

## CLI

```bash
tube-assistant              # interactive TUI menu (recommended)
tube-assistant onboard      # first-time setup wizard
tube-assistant start        # start the 24/7 daemon
tube-assistant run          # one-shot pipeline (one video now)
tube-assistant dry-run      # full pipeline, no upload (test your setup)
tube-assistant clips        # clip source: Pexels stock or AI video generation
tube-assistant preflight    # check keys, ffmpeg, credentials
tube-assistant update       # update to latest version
tube-assistant status       # show workspace and config
tube-assistant workspace    # print workspace path
```

Workspace: `~/.youtube-ai-agent/` by default, the current directory when run from a git clone,
or `YOUTUBE_AI_WORKSPACE` if set. Logs land in `<workspace>/logs/`.

### If you turn on AI video generation

Optional, off by default. A generated clip costs money — an 8-minute video is
~96 five-second segments, so generating all of them is expensive. That is why
the default when you enable it is **hybrid**: the AI covers the first clips
(the hook, where retention is won) and Pexels fills the rest.
`VIDEO_AI_MAX_CLIPS` is the per-video cap and is never exceeded; generated
clips are cached, so re-running the same topic does not pay twice.

| Mode | What it does |
|---|---|
| `pexels` | Stock only. Free. Default. |
| `ibrido` | First N clips generated, rest from Pexels. |
| `ai` | Every clip generated, no stock download. |

Configure it from the TUI (`tube-assistant clips`, or **Video clips** in the
menu): source, provider, API key, model and the cap. If the provider is down or
out of credit the pipeline falls back to Pexels instead of publishing a video
with no b-roll.

## Architecture

```
youtube_ai_agent/       CLI and launcher (pip entry point)
moduli/
  cervello.py           Topic and script generation (LLM)
  audio.py              Voice synthesis (Edge TTS)
  asset.py              Pexels clip download + AI clip pool assembly
  video_ai.py           AI video generation (Replicate / fal.ai / Luma / OpenRouter)
  impostazioni_video.py Clip-source settings screen (wizard + TUI)
  montaggio.py          Video editing (FFmpeg / MoviePy)
  thumbnail.py          AI thumbnail (Pollinations.ai / HuggingFace + Pillow)
  pubblica.py           YouTube Data API v3 upload
  analytics.py          Channel performance reading
  strategia.py          Strategy adaptation from analytics
  telegram_handler.py   Telegram bot (live control)
  ai_client.py          Multi-provider AI client
agent.py                Main daemon (24/7 scheduler)
wizard.py               Configuration wizard
```
